# SnippetBox

A full-stack snippet management application built to create, store, organize, and share code and text snippets.

## Tech Stack

* TypeScript
* Node.js
* Express.js
* PostgreSQL
* Prisma
* Zod

## Features

* User authentication
* Create and manage snippets
* Organize and search snippets
* Share snippets
